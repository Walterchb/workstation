Instalar y usar Work Hub

Publica tu agenda en GitHub Pages, conecta tu cuenta de Supabase y comprueba que tu primer registro se conserva al cambiar de dispositivo.

Actualizar con GitHub Desktop

Extrae el ZIP de actualización y copia su contenido en la carpeta de tu repositorio que contiene index.html. Acepta reemplazar los archivos coincidentes. Revisa Changes en GitHub Desktop, crea el commit y pulsa Push origin.

Work Hub carga las actividades, los objetivos generales y las categorías desde tu cuenta de Supabase. Si ya la configuraste, entra con tus credenciales habituales. Para una instalación nueva, sigue los pasos de conexión.

1. Preparar la base de datos

  1. Entra al panel de Supabase, selecciona tu organización y haz clic en New project. Elige un nombre como jornada-personal, la región disponible que prefieras y una contraseña para la base. Guárdala en tu gestor de contraseñas.
  2. Cuando el proyecto esté listo, abre SQL Editor en la barra lateral. Inicia una consulta con New query o el botón +.
  3. En la carpeta extraída, abre supabase/schema.sql con el Bloc de notas. Selecciona todo con Ctrl + A, copia y pega el contenido completo en la consulta. Pulsa Run.
  4. Espera el mensaje de éxito. En el esquema jornada_private se crea la tabla agendas. Cada fila pertenece a una cuenta. En public quedan las funciones de lectura y guardado. El script configura los permisos y activa la seguridad por fila (RLS).

Si elegiste las opciones estándar de un proyecto nuevo, el esquema public está disponible para la Data API. Si personalizaste el proyecto, verifica que la API esté habilitada y que public figure en sus esquemas expuestos. jornada_private debe permanecer privado.

2. Crear tu acceso personal

  1. Abre Authentication → Sign In / Providers. Comprueba que el proveedor Email esté habilitado. En la configuración de altas, desactiva Allow new users to sign up y guarda. Así, tú decides desde el panel a quién crearle una cuenta.
  2. Ve a Authentication → Users → Add user → Create new user. Ingresa tu correo y elige la contraseña que usarás en Work Hub.
  3. Marca Auto confirm user? y pulsa Create user. Esta opción confirma directamente la cuenta que estás creando. Verifica que tu correo aparezca en la lista de usuarios.

La contraseña de la base permite administrar PostgreSQL. Para el formulario de Work Hub usa el correo y la contraseña creados en este paso.

3. Conectar Work Hub con Supabase

  1. En la parte superior del proyecto, abre Connect y copia la Project URL. Tiene el formato https://tu-proyecto.supabase.co.
  2. Copia la Publishable key, que comienza con sb_publishable_. También puedes encontrarla en Settings → API Keys. Los proyectos antiguos pueden ofrecer una clave pública anon. Para un proyecto nuevo elige la clave publicable.
  3. En tu carpeta extraída, haz clic derecho en config.js y elige Abrir con → Bloc de notas. Sustituye los campos vacíos con los dos valores de tu proyecto, entre las comillas existentes. Guarda con Ctrl + S.
window.JORNADA_CONFIG = {
  supabaseUrl: "https://TU-PROYECTO.supabase.co",
  supabasePublishableKey: "sb_publishable_TU_CLAVE"
};

Ambos textos son ejemplos. Pega los valores que copiaste del mismo proyecto. El navegador puede ver este archivo. Work Hub conecta directamente con Supabase y carga la tipografía desde los archivos del sitio. Conserva la contraseña y las claves de servidor sb_secret_… y service_role exclusivamente en tus herramientas de administración.

4. Publicar el sitio en GitHub Pages

  1. En GitHub → New repository, crea un repositorio aparte con el nombre jornada-personal. Para usar Pages con GitHub Free personal, selecciona Public. Si tu plan admite Pages en repositorios privados, también puedes seleccionar Private. El sitio publicado puede ser accesible en internet incluso con el código en un repositorio privado. Los datos de tu agenda viven en Supabase.
  2. En el repositorio vacío, pulsa uploading an existing file. Si ya tiene un archivo, pulsa Add file → Upload files. Vuelve al Explorador de Windows y entra hasta ver index.html. Selecciona todo el contenido de esa carpeta y arrástralo a la página de GitHub. Conserva la estructura original.
  3. Pulsa Commit changes para guardar en main. Al abrir la pestaña Code, debes ver index.html y config.js al mismo nivel que las carpetas assets/ y supabase/. Si ves el ZIP o una sola carpeta contenedora, vuelve a cargar los archivos desde la carpeta que contiene index.html.
  4. Abre Settings → Pages → Build and deployment. En Source, selecciona Deploy from a branch. Elige main, /(root) y Save. Si creaste el repositorio con otro nombre de rama, elige la rama que contiene tus archivos.
  5. Consulta el avance en Actions. Una vez publicado, vuelve a Settings → Pages y abre Visit site. La dirección del ejemplo es https://TU-USUARIO.github.io/jornada-personal/. Guarda la dirección real en tus favoritos.

Si quieres dejar configurados los enlaces de autenticación del proyecto, copia la URL publicada con su carpeta de repositorio en Authentication → URL Configuration → Site URL de Supabase. El inicio directo por contraseña funciona sin redirecciones.

5. Comprobar que tu agenda quedó conectada

  1. Abre el sitio publicado. Debe aparecer el inicio de sesión. Ingresa con la cuenta que creaste en Supabase.
  2. Elige hoy en la barra superior. En Actividades, pulsa Editar actividades. En Planificar, escribe el título y contexto de tu primera actividad y pulsa Guardar jornada. Debe aparecer en Sin horario.
  3. Cierra sesión y abre el sitio en una ventana privada o en tu teléfono. Entra con la misma cuenta y selecciona la misma fecha. Debes encontrar la actividad que acabas de escribir.
  4. Para comprobar el aislamiento entre cuentas, crea una segunda cuenta de prueba desde Authentication → Users. Abre una ventana privada nueva, entra con ella y verifica que la agenda está vacía. La primera cuenta debe seguir conservando su actividad.

La sesión se guarda en la pestaña actual. Cuando la cierres, vuelve a entrar con tu correo para recuperar lo que guardaste en Supabase.

Registrar tu día de trabajo

Consultar el horario

Usa las flechas o el calendario de la barra superior para elegir la fecha. En Actividades, debajo de los indicadores y la Línea de tiempo, puedes alternar entre Horario, Lista y Semana.

  • Horario. Cada tramo ocupa el espacio que le corresponde por su duración. Las franjas rayadas Sin registro señalan los intervalos sin trabajo anotado. Cada hora tiene una altura de base reducida. El horario reserva más espacio donde lo necesita el contenido. Los tramos breves se muestran de forma compacta. Pulsa el título para leer el detalle completo.
  • Semana. Compara los días de lunes a viernes. Cada día del fin de semana se incorpora si tiene actividades, incluidas las que aún no tienen hora. Las flechas de la barra cambian de semana. Pulsa el encabezado de una fecha para abrir su horario diario.
  • Lista. Todos los tramos aparecen por hora de inicio, incluidos los más breves. Puedes consultar inicio, cierre, duración y comentarios, o abrir el detalle desde el título. La duración se expresa en horas y minutos. Por ejemplo, 0:10 equivale a diez minutos.

Las actividades que todavía no tienen horas aparecen en Sin horario, en el orden de tu plan. Las 08:00 son la referencia de entrada.

Planificar antes de las 08:00

Abre Editar actividades → Planificar. Escribe el título de la actividad en la fila que recibe el cursor. Pulsa Tab para escribir el contexto y Enter para seguir con otra fila. El contexto describe el objetivo específico del día.

  • Insertar una actividad. Usa el botón + de la fila que debe quedar encima. Para agregar al final, pulsa Añadir fila.
  • Traer tu plan desde Excel. Copia las columnas de actividad y contexto. Elige Pegar plan, revisa las filas y selecciona dónde incorporarlas.
  • Registrar más detalle. Cambia a Registro completo para trabajar en el orden de tu Excel. Allí puedes anotar estado, cumplimiento, horas y comentarios. Los dos modos comparten los cambios de la hoja.
  • Retomar una actividad del horario. Abre su título en la vista diaria o semanal y pulsa Editar actividad. La hoja se abre en la fila y la fecha correspondientes.

Desde Detalle de fila puedes asignar el objetivo general, la categoría, la prioridad y el origen. Marca Imprevista cuando la actividad se incorpore después de la planificación. Para reutilizar actividades de otro día, usa Reutilizar.

Organizar categorías

Abre Categorías en el menú lateral para cambiar los nombres y colores, crear categorías o elegir una predeterminada. Al cambiar un nombre se actualizan las actividades vinculadas. Una categoría archivada se conserva en los registros que ya la utilizaban.

Al empezar y al cambiar de actividad

Selecciona la fila y escribe tu Hora de inicio. Si trabajas en la fecha de hoy, Marcar inicio toma la hora actual de Lima. Pulsa Guardar jornada para dejar registrado el inicio. Cuando termines, vuelve a Editar actividades, escribe la Hora de cierre o pulsa Marcar cierre, y registra el comentario. Si retomas el encargo más tarde, usa Añadir tramo en esa misma fila. Si un tramo de hoy sigue abierto, puedes ver el tiempo transcurrido. El indicador de tiempo registrado solo suma los tramos cerrados.

Guardar jornada o Ctrl + S guarda de una vez los cambios del editor y actualiza el horario. Si intentas cerrar la hoja con cambios pendientes, puedes seguir editando o descartarlos.

Preparar el informe gerencial

Actualiza los comentarios con lo que avanzaste y, cuando se concrete un resultado, regístralo con su fecha en Objetivos generales. El estado de una actividad y la casilla ¿Se hizo? son independientes. Puedes haber cumplido lo previsto para hoy aunque el encargo siga en proceso.

En Análisis, selecciona Diario o Semanal, elige el período y abre Informe gerencial → Descargar PDF. El informe incluye todas las actividades del período, incluso las pendientes o sin horas. Para cada una muestra el título como Actividad, el contexto como Objetivo específico y los comentarios como Evidencia registrada. Las actividades se agrupan por Objetivo general. Si has confirmado resultados en el período, se incluyen en el resumen.

Resolver problemas frecuentes

La configuración aparece incompleta
Completa ambos campos del archivo con los valores del mismo proyecto. Conserva las comillas, la coma y el nombre exacto config.js. Sube el cambio y espera a que se publique.
GitHub muestra 404 o faltan los estilos
Abre la dirección de Visit site. Revisa que la fuente sea la rama correcta y /(root), que index.html esté en la raíz y que la carpeta assets/ conserve su nombre y sus archivos.
El formulario rechaza el correo o la contraseña
Verifica el correo en Authentication → Users, su confirmación y que el proveedor Email esté activo. Comprueba que hayas usado la contraseña de esa cuenta y la URL de ese mismo proyecto.
La cuenta inicia, pero aparece un error al leer o guardar
Revisa tu conexión y que el proyecto de Supabase esté activo. Comprueba el resultado de schema.sql en SQL Editor y, si quedó incompleto, vuelve a ejecutar el archivo completo. Revisa en la configuración de la Data API que el esquema public esté expuesto.
Otra sesión modificó la agenda mientras editabas
En la hoja de actividades, abre Opciones de fila → Copiar hoja y pega el borrador en Excel. Recarga la página, comprueba qué se guardó desde el otro dispositivo y vuelve a aplicar tu cambio.
