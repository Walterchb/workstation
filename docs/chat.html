Volver a Work Station

Activar el chat de Work Station

El chat consulta tus registros mediante tu sesión de Work Station. Para activarlo por primera vez, guarda una clave de la API de OpenAI en tu proyecto de Supabase, publica la función workhub-chat y sube la actualización de la web.

Si tu chat ya funciona

  1. Descomprime el ZIP. En tu proyecto de Supabase abre Edge Functions → workhub-chat → Code y selecciona index.ts. Reemplaza su contenido con el archivo instalacion/workhub-chat/index.ts del nuevo ZIP. Pulsa Deploy updates o Deploy function y espera la confirmación. Puedes seguir usando la misma clave y el mismo modelo.
  2. Copia el contenido del ZIP en la raíz de tu repositorio, junto al index.html actual. Acepta el reemplazo de los archivos coincidentes. En GitHub Desktop pulsa Commit to main → Push origin. Después de la publicación de Pages, vuelve a cargar Work Station.
  3. Abre Actividades → Semana, aplica un filtro y abre el widget. Verás el período encima de la conversación. Prueba «¿Qué cambió aquí según mis comentarios?» y después «¿Qué sigue esperando respuesta?». Abre una cita para comprobar el comentario original.

Configurar el indicador de créditos

Abre Saldo del chat → Actualizar saldo. Copia el Credit balance en USD que ves en Billing de OpenAI e indica cuándo lo consultaste. En el móvil, activa la edición para guardar el saldo. Abrir Billing de OpenAI

Con tres preguntas medidas del mismo modelo, la pestaña muestra los créditos estimados. Un crédito equivale al costo medio de una consulta, calculado con hasta 30 respuestas recientes. En el widget, el anillo muestra qué proporción del último saldo registrado queda disponible. Es verde por encima del 50 %, amarillo entre el 15 % y el 50 % inclusive y rojo por debajo del 15 %. Si falta el saldo o hay consumo sin medir, aparece un anillo gris discontinuo.

Toca el indicador para ver el detalle. El cálculo cubre esta cuenta en este navegador. Actualiza la referencia después de una recarga o de consumir saldo desde otro dispositivo o aplicación.

Si un intento queda sin medición o falta la tarifa del modelo, el indicador te pedirá revisar el saldo. Para un modelo con una tarifa especial, puedes definir WORKHUB_CHAT_RATES_JSON en los secretos de la función con las tarifas de tu proyecto en USD por millón de tokens. El formato es {"identificador-del-modelo":{"input":1,"cached":0.2,"output":4}}. Los importes de ese ejemplo son ilustrativos.

1. Conseguir la clave de OpenAI

  1. En la plataforma de OpenAI, elige la organización y el proyecto que usarás para el chat. En Billing, comprueba que tienes créditos activos o facturación habilitada. El consumo se calcula según el uso de la API. Algunos planes de ChatGPT permiten activar créditos de API para una organización elegible. Abrir Billing · Consultar la elegibilidad
  2. En API keys, elige Create new secret key. Ponle un nombre reconocible, por ejemplo Work Station, y copia el valor. Pégalo únicamente en el campo secreto del siguiente paso. Abrir API keys

2. Guardar la clave en Supabase

  1. Abre el proyecto Work-Station que usas para la agenda y entra en Edge Functions → Secrets.
  2. En Key escribe exactamente OPENAI_API_KEY. En Value pega la clave de OpenAI y pulsa Save. Al terminar, verás el nombre del secreto en el listado. El repositorio, el archivo config.js y los mensajes del chat deben quedar libres de esta clave.
Elegir otro modelo (opcional)

El chat usa gpt-6.2-sol de forma predeterminada. Para cambiarlo, crea en el mismo panel un secreto llamado OPENAI_MODEL y usa como valor el identificador de un modelo habilitado en tu proyecto que admita Responses API y llamadas a funciones. Ficha del modelo predeterminado

3. Comprobar la función del chat

En Edge Functions → Functions, busca workhub-chat. Si ya existe, sigue la sección Si tu chat ya funciona para actualizarla. Usa los pasos siguientes para su primera instalación.

  1. En Edge Functions → Functions, pulsa Deploy a new function → Via Editor. El editor abrirá una función nueva con código de ejemplo. La función que debes crear en este paso se llama workhub-chat.
  2. Descomprime el ZIP de la actualización y abre instalacion/workhub-chat/index.ts con el Bloc de notas o tu editor de texto. Copia todo su contenido. En el editor de Supabase, selecciona el archivo index.ts y reemplaza todo el código de ejemplo por el que acabas de copiar. Este archivo reúne el código completo para el editor.
    Abrir archivo de instalación
  3. En Function name, al pie del editor, escribe workhub-chat y pulsa Deploy function. Espera el mensaje de éxito. En el listado verás la función nueva junto a workhub-calendar.
  4. En los detalles de workhub-chat, deja activada la verificación JWT de Supabase. La aplicación enviará el token de la persona que inició sesión y la función comprobará su identidad antes de consultar la agenda.

4. Publicar la web y probarla con un registro tuyo

  1. Copia el contenido del ZIP en la carpeta de tu repositorio donde está index.html, conservando las subcarpetas. En GitHub Desktop revisa los cambios, escribe Agregar chat a Work Station y pulsa Commit y después Push origin.
  2. Cuando GitHub Pages termine de publicar, abre tu página, recarga e inicia sesión. En la barra lateral elige Chat. En otras vistas puedes abrir el botón de chat de la esquina inferior derecha. La ventana y la pestaña comparten la conversación y el borrador del ámbito elegido. Verás el progreso de la consulta y podrás leer la respuesta a medida que se escribe. Al terminar, las referencias permiten abrir los registros citados.
  3. Busca en tu calendario la fecha de una reunión que ya registraste. En el chat selecciona Calendario y sustituye la fecha de esta pregunta por la de tu reunión.
    ¿Qué reuniones tengo el 26 de noviembre? Indica la hora y muéstrame el registro.
    Abre la referencia de la reunión en la respuesta y compara el título y la hora con el evento original. Si la fecha seleccionada no tiene reuniones, prueba con una fecha que sí las tenga.

Qué información se utiliza

Al enviar una consulta, la función comunica a OpenAI tu pregunta, el contexto visible, los temas recientes del hilo y los registros o totales pertinentes del ámbito elegido. Al retomar un asunto, puede volver a abrir los registros citados con tu sesión. Por ejemplo, en Calendario puede consultar el título, el horario y la descripción de un evento. El chat es de solo lectura. La clave de OpenAI queda en Supabase.

La conversación se mantiene en memoria durante la sesión de la página. La función solicita a OpenAI que desactive el almacenamiento de la respuesta mediante store: false. El tratamiento de datos y los registros de prevención de abusos se rigen por los controles de datos de tu organización de API. Consultar los controles de datos

Resolver problemas de activación
Ves la agenda, pero falta Chat en la barra lateral.
Comprueba que GitHub Desktop envió el commit con el archivo index.html actualizado, espera a que termine la publicación de GitHub Pages y recarga la página.
Work Station indica que falta la función.
Abre el proyecto de Supabase vinculado a tu agenda. En Edge Functions → Functions, comprueba que aparece exactamente workhub-chat y que finalizó la publicación.
El chat pide iniciar sesión.
Vuelve a ingresar con tu cuenta de Work Station y envía la consulta desde la página. Abrir directamente la URL de la función en otra pestaña no inicia una consulta autenticada.
El chat informa que falta la clave, el modelo no está disponible o se agotaron los créditos.
Revisa OPENAI_API_KEY en los secretos de Supabase, el modelo habilitado para tu proyecto si elegiste uno y los créditos disponibles en Billing. Después vuelve a enviar la consulta.
