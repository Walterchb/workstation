Ver un calendario de Work Hub en Apple

La suscripción muestra en Apple los eventos y reuniones del calendario que elijas. Crea o modifica los eventos en Work Hub. Apple consulta el enlace periódicamente, por lo que los cambios pueden tardar en aparecer.

1. Activar el servicio en tu proyecto Supabase

Si ya usas una suscripción, copia primero la actualización en tu repositorio y publícala con GitHub Desktop. En el proyecto de Supabase de Work Hub, ejecuta el SQL actualizado y reemplaza el código de la función workhub-calendar existente. Se conserva tu enlace de calendario completo.

  1. Abre SQL Editor → New query en Supabase. Pega el contenido de supabase/apple-calendar.sql y pulsa Run. Verás una confirmación de éxito.
  2. En Edge Functions, abre el editor de workhub-calendar. Si es la primera instalación, selecciona Deploy a new function → Via Editor y dale ese nombre. Reemplaza todo el contenido de index.ts con el archivo actualizado supabase/functions/workhub-calendar/index.ts. Pulsa Deploy.
  3. En el detalle de workhub-calendar, desactiva Verify JWT (o Verify JWT with legacy secret) y guarda. Apple consulta la función mediante un enlace privado. La función verifica su código secreto cada vez que recibe una petición.
Publicar la función desde la terminal

Si usas la CLI de Supabase, puedes publicar la función después de ejecutar el SQL. Desde la carpeta de Work Hub que contiene index.html, reemplaza TU_PROJECT_REF por el identificador de tu proyecto.

supabase login
supabase projects list
supabase functions deploy workhub-calendar --project-ref TU_PROJECT_REF --no-verify-jwt --use-api

2. Suscribirte desde iPhone o Mac

  1. En Work Hub → Calendario → Calendario de Apple, elige tu calendario de origen, por ejemplo Trabajo, y pulsa Continuar.
  2. Usa Por categoría si quieres distinguir tus categorías por color en Apple. Elige una categoría, pulsa Activar suscripción y después Abrir en Calendario de Apple. Repite estos pasos con cada categoría que quieras ver, incluida Sin categoría si la usas. Al crear una categoría nueva que quieras ver en Apple, suscríbete una vez a su enlace. Para ver todos los eventos con un solo color, elige Calendario completo.
  3. También puedes elegir Copiar enlace. En el iPhone, abre Calendario → Calendarios → Agregar calendario → Agregar calendario de suscripción y pega la URL. En la Mac, usa Archivo → Nueva suscripción a calendario.
  4. Elige iCloud como cuenta o ubicación si quieres que la suscripción aparezca en los dispositivos conectados a tu cuenta de Apple. Repite la suscripción para cada calendario que quieras ver.

Quien tenga el enlace puede leer los eventos de ese calendario, incluido su lugar y descripción. Desactivar enlace interrumpe las consultas. Al reactivarlo se genera una URL nueva. Para retirar eventos que Apple haya conservado, elimina la suscripción desde Calendario.

El color de las categorías

En Apple, cada suscripción tiene un color. Work Hub envía el nombre y el color de cada categoría en su enlace. Si Apple muestra otro tono, copia el código de color que aparece en Work Hub. En la Mac, haz clic con la tecla Control sobre el calendario y selecciona el color personalizado. En el iPhone, entra a Calendario → Calendarios → ⓘ → Color.

Si ya tienes el calendario completo, comprueba primero que aparezcan los eventos de tus categorías. Después puedes cancelar la suscripción al calendario completo en Apple para evitar eventos y avisos duplicados. Tus eventos originales siguen en Work Hub.

Un evento eliminado sigue en Apple

Recarga Work Hub y comprueba que el evento haya desaparecido. Si usas una suscripción, Apple verá el cambio la próxima vez que consulte el enlace. Para pedir una actualización en el iPhone, abre Calendario → Calendarios y desliza la lista hacia abajo. Si el evento sigue visible, ábrelo y revisa el campo Calendario. Una copia que agregaste al importar un archivo .ics se elimina directamente en el calendario donde la guardaste.

La hora en Lima

Los eventos con horario se envían con la zona de origen America/Lima. Una reunión registrada a las 09:00 se publica a las 09:00 de Lima. Si tras la actualización todavía ves GMT, revisa en el iPhone Configuración → Apps → Calendario → Anulación de zona horaria. Si está activa con otra ciudad, selecciona Lima o desactiva la anulación para usar la ubicación del teléfono.

Avisos de los eventos

Al crear un evento en Work Hub, elige cuándo quieres el aviso. La suscripción y la descarga incluyen esa antelación, también cuando reutilizas el evento. Para recibir los avisos en la Mac, permite las notificaciones de Calendario y comprueba en la información del calendario que Ignorar avisos esté desactivado.

Importar una copia puntual

En el mismo diálogo, elige Descargar. El archivo .ics funciona desde la primera instalación de Work Hub, incluso antes de activar el servicio en Supabase. En la Mac, abre el archivo y elige el calendario de destino. Esta copia contiene los eventos del momento de la descarga.
